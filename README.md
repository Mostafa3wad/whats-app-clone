# ⭐ WhatsApp Clone – Real-Time Messaging App

This project is a **WhatsApp-like real-time messaging application** built with a modern mobile-first architecture.  
It focuses on delivering fast, secure, and reliable communication with a clean and intuitive UI.

---

## 🚀 Features

### 💬 Real-Time Chat  
- One-to-one messaging  
- Group chats  
- Read receipts (double-check style)  
- Real-time messaging  

### 📁 Media Support  
- Send images  
- Send videos  
- Send documents & files  

### 🔐 Authentication  
- Phone number authentication  
- OTP verification  

### 👥 Group Features  
- Create & manage groups  
- Add/remove participants  
- Group media and shared files  

---

## ⚡ Core Highlights  
- Fast real-time communication  
- Scalable architecture  
- Clean and modular codebase  
- Mobile-optimized experience  

---

## 📱 Platform  
The application is fully built for **mobile**, offering fluid navigation and a familiar messaging experience.

---

## 📌 Purpose  
A complete end-to-end learning and production-ready architecture for building real-time chat applications similar to WhatsApp.
